Every HTTP request that reaches the API counts once, under its method and route template, so player tags and queries share a row. Times run from the request reaching the API to its last byte leaving: nginx, the network and WebSockets are not included, and neither are requests nginx answers itself, such as a 502 while the API is down. Percentiles come from bucketed histograms and are exact to the bucket; one past the top bucket reads "≥ 10s" and plots at 10s. Breaks in a line mean the API reported no samples: it was down, or it could not write them.
